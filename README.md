## 🚀 Ce que je développe

### 🎮 Extensions Pterodactyl
Je développe des **extensions pour Pterodactyl V2** :
- Des personnalisations des pages admin/clients
- Des outils de gestion de serveur et d'utilisateurs

### 🤖 Bots Discord (JavaScript)
- Bots de modération et d'utilitaires

### 🎵 Addons Lavalink
Je développe des **addons liés à Lavalink**, le serveur audio dédié pour Discord :
- Dashboard avancé pour configurer Lavalink à distance
- Filtrage de connexion avancé

### 🌐 Développement Web (PHP / HTML / CSS)
En parallèle, je réalise des sites web et des interfaces avec :
- **PHP** pour le backend et la logique serveur
- **HTML5 / CSS3** pour l'interface et l'expérience utilisateur
- **MySQL** pour le stockage de données
